A cleanup loop you can audit

Ultimate De-Slop keeps agents useful without letting them sprawl. The deterministic harness owns state, checks, scoring, snapshots, and stop conditions; agents stay inside narrow roles.

What it prevents

  • open-ended rewrites
  • style churn disguised as quality work
  • silent success after a partial agent run
  • unreviewed accumulation across fixes

What it records

  • candidate findings and arbitration
  • prompts, raw output, and extracted JSON
  • deterministic check results
  • verifier decisions and loop state

The bounded loop

Each stage has a role, a permission boundary, and a concrete artifact.

1

Inventory

Map source files, likely commands, risk partitions, and large-file pressure.

2

Review

Read-only structural review reports only concrete P0, P1, or bounded P2 findings.

3

Arbitrate

Weak, duplicate, vague, low-confidence, or subjective findings are rejected.

4

Fix

The fixer edits exactly one accepted finding and records before/after snapshots.

5

Check

Expected commands run through a conservative allowlist and write traceable logs.

6

Verify

A separate read-only verifier judges the patch against the original finding.

Install and run

Install the skill for your preferred harness, then run the loop from the repository you want to improve.

git clone https://github.com/Niko96-dotcom/ultimate-de-slop.git
cd ultimate-de-slop
scripts/install/install-codex.sh

SKILL_DIR="$HOME/.codex/skills/ultimate-de-slop"
cd /path/to/your/repo
"$SKILL_DIR/scripts/deslop-init.sh"
"$SKILL_DIR/scripts/deslop-loop.sh" --max-iterations 5 --priority P0,P1

Local artifacts

Runtime state stays in the target repository under `.deslop/`, where it can be inspected, resumed, or removed.

config

iteration limits, confidence thresholds, timeouts, and ignored paths

findings

append-friendly finding lifecycle records with status transitions

runs

prompt files, raw output, extracted JSON, runner metadata, and check logs

state

score, counters, stop state, current iteration, and next suggested command
